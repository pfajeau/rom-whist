User Guide

Creating and joining a game

You can either create a new game, or join an existing game. Somebody first need to create a game. Then the game creator has to inform other players of the game id so they can join the newly created game.

When creating or joining a game, each player has to specify their alias for the game. The computer does not play, so all players have to be real persons

When creating the game, one can specify the number of points a player or team must reach to win the game

Playing

Whenever a player has to do something (bid, or play), the player alias flashes to remind the player that they have to do something. To play a card, just clik that card. Cards that can be played have a green border.

Summary of the game play rules:

  • One always has to play the suit being asked. If the suit asked is trump, then one has to play a higher trump than the highest card played if possible.
  • If ones does not have a card from the asked suit, and if one's partner has not played the winning card (or has not played yet), one must play a trump card if possible. Otherwise one can play any card.
  • If a player from another team has already cut and is winning the round, and one has to cut, then one has to cut above that player card, If it is not possible, one must play a smaller trump.
  • If one's partner is winning the round and one does not have the asked suit, then one can play any card they wish

Scoring

Points for the current hand are displayed in the "Points" fields. Score represents the overall score for each player or team.
