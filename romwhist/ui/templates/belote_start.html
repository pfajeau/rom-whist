User Guide

Creating and joining a game

You can either create a new game, or join an existing game. Somebody first need to create a game. Then the game creator has to inform other players of the game id so they can join the newly created game.

When creating or joining a game, each player has to specify their alias for the game. The computer does not play, so all players have to be real persons

Playing

Whenever a player has to do something (bet, or play), the player alias flashes to remind the player that they have to do something. To play a card, just clik that card. Cards that can be played have a green border.
